Problem: Developers often struggle to accurately document code changes, identify potential side effects, select appropriate reviewers, and keep project documentation up to date. Existing AI commit-message tools can generate misleading descriptions that are not supported by the actual code changes, reducing trust and making code reviews less effective.
Objective: Build CommitWise, an AI-powered code review assistant using Gemma 4 that analyzes Git changes, generates evidence-based commit messages, identifies potential risks, recommends suitable reviewers, and flags outdated documentation. The system should link its recommendations to actual code changes wherever possible, helping developers verify AI-generated claims before committing or reviewing code.# CommitWise_Hacktoberfest
